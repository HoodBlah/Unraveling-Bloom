Put the Botania Revived jar here (NOT the -sources jar).

1. Unzip Botania-Revived-Neo-1_21_1.zip
2. In that folder run:  gradlew build      (Windows: .\gradlew.bat build)
3. Copy the jar from its build/libs/ folder (e.g. "Botania Revived-1.21.1-1.0.3-....jar") into this libs/ folder
4. Back in this project run:  .\gradlew.bat build
